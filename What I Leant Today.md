Today, I revised **Linear Regression and the Cost Function** through Andrew Ng’s AI/ML course on Coursera.

I already had a basic understanding of the cost function, but I was a little confused about where it fits into the overall learning process. I revisited the concept and clarified the sequence:

1. **Prediction:** The model uses the hypothesis equation \(\hat{y} = wx + b\) to make predictions.
2. **Cost Function:** We compare the predicted values with the actual values and calculate the cost to measure how much error the model is making.
3. **Gradient Descent:** It uses the calculated gradients to update the parameters \(w\) and \(b\), aiming to reduce the cost.
4. **Iteration:** This process repeats until the model reaches a good fit by minimizing the cost.

The key takeaway for me was understanding that the prediction equation generates predictions, the cost function evaluates how well those predictions match the actual values, and Gradient Descent improves the model by adjusting its parameters.
